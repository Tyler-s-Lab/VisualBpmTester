# VisualBpmTester

## 2025/02/22

决定优化旧方案，同时放弃该方案。

该方案实现难度还是太大，收益与付出不成正比。

为了获取歌曲的BPM，最简单的方式是```上网搜索```。

其次就是把旧项目愚蠢的算法，改成正确的打点计时器算法，确保结果必然收敛到正确值。

这个项目本来是计划做成 可视化峰值电平 然后自由拖动音符位置 从而在全曲的尺度上保证节奏准确。

### 解释

初始时点击两个相邻音符位置，程序自动将音符铺满整个乐曲。然后可以拖动任意一个音符来微操。

### 难点

拖动任意音符时应该选择哪个音符为不动点来缩放？是最初的那个音符吗？

目前的可视化电平效果并不好，有些声音大的乐曲根本看不出节奏。

### 结论

放弃本项目并归档。
